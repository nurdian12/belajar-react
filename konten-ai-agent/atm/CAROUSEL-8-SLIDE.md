# Langkah 4: 5 carousel siap produksi (8 slide) untuk @alamnurdiann

Format semua: carousel 8 slide. Struktur: 1 Hook, 2 Masalah, 3-5 Solusi, 6 Contoh/Demo, 7 Kesimpulan, 8 CTA.
Aturan: tidak ada hasil eksperimen, angka, atau pengalaman pribadi yang dikarang. Semua contoh berlabel "Contoh ilustrasi".
Sumber rujukan untuk definisi workflow vs agent: Anthropic, "Building effective agents" (anthropic.com/engineering/building-effective-agents).
CTA kata kunci: **AGENT** -> paket template dan checklist AI agent (hadiah dibuat setelah kamu menyetujui isinya).

---

## 1. Ini agent atau bukan? (pintu masuk pemula)

| Slide | Teks di layar |
|---|---|
| 1 Hook | **Tidak semua yang disebut AI agent itu agent.** Tes 3 pertanyaan di slide 5. |
| 2 Masalah | Istilah "agent" dipakai untuk banyak hal berbeda. Salah paham bikin kamu membangun atau membeli hal yang salah. |
| 3 Solusi | **Workflow:** alurnya sudah ditentukan lewat kode. Model hanya mengerjakan langkah-langkahnya. |
| 4 Solusi | **Agent:** model mengarahkan prosesnya sendiri dan memilih alat serta langkah berikutnya. (Sumber: Anthropic, Building effective agents) |
| 5 Solusi | **Tes 3 pertanyaan:** 1) Urutan langkahnya selalu sama? Ya, itu workflow. 2) Model memilih sendiri alat atau langkah berikutnya? Ya, itu agent. 3) Ia bisa berhenti, bertanya, atau mengubah rencana? Condong ke agent. |
| 6 Contoh | *Contoh ilustrasi.* Ringkas email tiap pagi, urutan tetap: workflow. Riset yang jalurnya tiap kali berbeda: agent. Satu pertanyaan, satu jawaban: chatbot. |
| 7 Kesimpulan | Alur pasti: workflow dulu. Jalur berubah-ubah: agent. Keduanya sah. Sesuaikan dengan tugas. |
| 8 CTA | Tugasmu masuk yang mana? Tulis tugasnya di komentar. Simpan dulu biar tidak lupa. |

**Caption:** Banyak orang bilang "AI agent", tapi maksudnya beda-beda. 🤔 Geser untuk tes 3 pertanyaan: ini workflow, agent, atau cuma chatbot? Tugasmu masuk yang mana? Tulis di komentar. 👇
**Hashtag:** #aiagent #aiautomation #belajarai #aiindonesia #produktivitas

## 2. Instruksi agent = brief karyawan baru (salin-tempel)

| Slide | Teks di layar |
|---|---|
| 1 Hook | **Kalau karyawan baru bingung, agent juga.** Instruksimu sudah selengkap brief? |
| 2 Masalah | Agent tidak tahu apa yang ada di kepalamu. Instruksi singkat dan samar membuat hasilnya meleset. |
| 3 Solusi | Yang paling sering hilang: **tujuan**, **batasan**, dan **kriteria selesai**. |
| 4 Solusi | Brief 6 bagian: TUGAS, LATAR BELAKANG, HASIL YANG DIHARAPKAN, YANG BOLEH, YANG TIDAK BOLEH, KALAU RAGU. |
| 5 Solusi | **Template salin-tempel:** `TUGAS: ... / LATAR BELAKANG: ... / HASIL: ... / BOLEH: ... / TIDAK BOLEH: ... / KALAU RAGU: tanya aku dulu.` |
| 6 Contoh | *Contoh ilustrasi.* TUGAS: rangkum catatan rapat. HASIL: 5 poin dan daftar tugas. TIDAK BOLEH: menambah info yang tidak ada di catatan. KALAU RAGU: tanya. |
| 7 Kesimpulan | Brief jelas = revisi lebih sedikit. Simpan versi yang berhasil jadi template. |
| 8 CTA | Komen **AGENT**, nanti aku kirim paket template dan checklist agent. |

**Caption:** Instruksi singkat itu sering jadi sumber hasil yang meleset. 😅 Coba perlakukan agent seperti karyawan baru: kasih brief lengkap. Template-nya ada di slide 5, tinggal salin. Komen **AGENT** buat dapat paket template lengkapnya. 👇
**Hashtag:** #aiagent #templateprompt #promptengineering #belajarai #aiindonesia

## 3. Pekerjaan admin yang cocok dan tidak cocok diserahkan

| Slide | Teks di layar |
|---|---|
| 1 Hook | **Tidak semua pekerjaan admin boleh diserahkan ke agent.** |
| 2 Masalah | Kalau semuanya diserahkan, satu kesalahan kecil bisa jadi besar. |
| 3 Solusi | 3 kriteria tugas yang cocok: aturannya jelas, dampak salah kecil, hasilnya mudah dicek. |
| 4 Solusi | **Cocok (contoh ilustrasi):** merapikan catatan, mengelompokkan data, menyusun draf balasan. |
| 5 Solusi | **Belum cocok (contoh ilustrasi):** keputusan keuangan tanpa tinjauan, pesan sensitif tanpa persetujuan, hal yang tidak bisa dibatalkan. |
| 6 Contoh | Jalan tengah: agent menyiapkan **draf**, manusia yang **menyetujui** sebelum dikirim. |
| 7 Kesimpulan | Mulai dari tugas yang aman. Longgarkan setelah terbukti. |
| 8 CTA | Pekerjaan admin apa yang paling ingin kamu serahkan? Tulis di komentar. |

**Caption:** Pekerjaan admin yang itu-itu saja memang menggoda untuk diserahkan ke agent. Tapi tidak semuanya aman. ⚖️ Geser untuk 3 kriteria menentukan mana yang cocok dan mana yang belum. Pekerjaan apa yang pengin kamu serahkan? 👇
**Hashtag:** #aiagent #aibisnis #otomatisasi #umkm #aiindonesia

## 4. Kapan agent belum layak untuk UMKM

| Slide | Teks di layar |
|---|---|
| 1 Hook | **Agent bisa jadi pemborosan untuk usahamu.** Hitung dulu sebelum bangun. |
| 2 Masalah | Tren membuat orang membangun dulu, menghitung belakangan. |
| 3 Solusi | **Pertanyaan 1: Frekuensi.** Seberapa sering tugas ini dikerjakan? Jarang? Manual mungkin lebih murah. |
| 4 Solusi | **Pertanyaan 2: Risiko.** Kalau salah, apa dampaknya? Dampak besar butuh persetujuan manusia. |
| 5 Solusi | **Pertanyaan 3: Biaya.** Waktu membangun dan memantau ikut dihitung. **Pertanyaan 4: Bisa dicek?** Hasil sulit dinilai = sulit dipercaya. |
| 6 Contoh | *Contoh ilustrasi.* Balasan FAQ harian: sering, risiko rendah, mudah dicek: layak dicoba. Tugas sebulan sekali dengan data sensitif: jangan dulu. |
| 7 Kesimpulan | Anthropic mencatat sistem agent bisa menambah latensi dan biaya, jadi tambahkan kompleksitas hanya kalau memang membantu. (Sumber: Building effective agents) |
| 8 CTA | Komen **AGENT** untuk checklist 4 pertanyaan ini versi siap pakai. |

**Caption:** Sebelum membangun agent untuk usahamu, jawab 4 pertanyaan ini dulu. 🧮 Kadang jawabannya: belum perlu. Itu bukan kegagalan, itu hemat. Komen **AGENT** buat checklist-nya. 👇
**Hashtag:** #aiagent #aibisnis #umkm #otomatisasi #aiindonesia

## 5. Menilai tool agent baru dalam 5 pertanyaan

| Slide | Teks di layar |
|---|---|
| 1 Hook | **Ada tool agent baru? Tanya 5 hal ini dulu.** |
| 2 Masalah | Setiap minggu ada tool baru. Menyambungkannya ke akun asli tanpa dicek bisa merepotkan. |
| 3 Solusi | **1) Akses:** apa saja yang bisa dibaca dan diubah? |
| 4 Solusi | **2) Log:** bisa lihat tiap langkah? **3) Batas:** bisa batasi langkah, biaya, dan izin? |
| 5 Solusi | **4) Biaya:** tarifnya jelas dan bisa dibatasi? **5) Keluar:** data bisa diekspor dan akses bisa dicabut? |
| 6 Contoh | *Contoh ilustrasi dengan tool fiktif.* Akses terbatas: ya. Log: ya. Batas biaya: tidak. Ekspor data: ya. Kesimpulan: coba di akun uji dulu. |
| 7 Kesimpulan | Coba di akun uji, bukan akun asli. Naikkan akses bertahap. |
| 8 CTA | Simpan buat dipakai saat ada tool baru, dan kirim ke temanmu yang gampang tergoda tool baru. |

**Caption:** Tool agent baru muncul terus. 🚨 Sebelum disambungkan ke akunmu, tanyakan 5 hal ini. Simpan dan kirim ke temanmu yang gampang FOMO.
**Hashtag:** #aiagent #aitools #belajarai #aiindonesia #produktivitas
