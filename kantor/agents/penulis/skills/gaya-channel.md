# Skill: Gaya channel

Ubah file ini sesuai channel kamu (niche, nada, sapaan, penutup khas).

- Niche: (isi, mis. tips keuangan pribadi / edukasi sains / bisnis UMKM)
- Nada: hangat, to the point, tanpa menggurui
- Sapaan penonton: "kamu"
- Penutup: ajakan ringan untuk menyimpan atau membagikan video
