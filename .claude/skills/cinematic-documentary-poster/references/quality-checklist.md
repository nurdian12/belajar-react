# Prompt quality checklist

Before returning a prompt, verify:

- [ ] One focal subject and one readable visual story.
- [ ] The scene supports the topic rather than adding unrelated sensational props.
- [ ] Historical setting and objects are plausible for the stated period.
- [ ] The headline is concise, spelled exactly, and not misleading.
- [ ] Unverified claims are clearly framed as claims or allegations.
- [ ] Text has a reserved, uncluttered area and strong contrast.
- [ ] Aspect ratio matches the intended platform.
- [ ] Negative prompt addresses common image-generation failures.
